## 📚 Contenido del Repositorio

En este laboratorio se desarrollaron diferentes aplicaciones de escritorio utilizando **C#** y **Windows Forms** en **Visual Studio**, enfocándose en la implementación de interfaces gráficas organizadas mediante contenedores MDI, lógica de juegos y manipulación de controles avanzados.

El repositorio está compuesto por dos proyectos principales:

- 📊 **Práctica 1 - Uso de DataGridView**
- 🎲 **Práctica 2 - Juego de Craps**
- 🗂️ **Práctica 3 - Interfaz MDI (Multiple Document Interface)**
  
---

- 🧩 **Framework:** .NET / .NET Framework

### 🎲 Problema 2: Juego de Craps (`Lab3_Juegp de Craps`)

En este ejercicio se programó la lógica del clásico juego de apuestas y dados de Craps, aplicando estructuras de control y gestión de eventos dentro de un formulario de Windows Forms.

La aplicación simula el lanzamiento de dados y evalúa las reglas del juego para determinar si el usuario gana, pierde o continúa tirando.

### 🗂️ Problema 3: Aplicación MDI (`Lab3_MDI`)

En este ejercicio se desarrolló una interfaz de múltiples documentos (MDI), permitiendo abrir y gestionar formularios secundarios (hijos) dentro de un formulario contenedor principal (padre).

Esta arquitectura facilita la navegación y la organización de múltiples ventanas o módulos dentro de una misma aplicación de escritorio.
