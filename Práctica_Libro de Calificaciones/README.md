# 📖 Práctica - Libro de Calificaciones

**Fecha:** 08/09/2026

---

## 📚 Contenido del Repositorio

En esta práctica se desarrolla el programa **Libro de Calificaciones**, utilizando el lenguaje **C#**.

Se trabajan diferentes formas de controlar la repetición para calcular el promedio de las calificaciones introducidas por el usuario.

La práctica contiene dos ejercicios:

- 🔢 Repetición controlada por contador
- 🚦 Repetición controlada por centinela

---

## 🛠️ Tecnologías Utilizadas

- 💻 **Lenguaje:** C#
- 🧩 **Framework:** .NET
- 🖥️ **IDE:** Visual Studio
- 📦 **Control de versiones:** Git & GitHub

## 📸 Capturas de Pantalla y Problemas

### 🔢 Problema 1: Repetición controlada por contador

En este ejercicio se calcula el promedio de una cantidad determinada de calificaciones.

El programa solicita **10 calificaciones**, calcula el total y posteriormente obtiene el promedio de la clase.

Finalmente, se muestran en pantalla:

- 📝 Total de las calificaciones
- 📊 Promedio de la clase

### 🚦 Problema 2: Repetición controlada por centinela

En este ejercicio se utiliza un valor centinela para controlar la repetición.

El usuario puede introducir diferentes calificaciones y utilizar **-1** para indicar que desea finalizar el ingreso de datos.

Al finalizar, el programa calcula:

- 📝 Cantidad de calificaciones introducidas
- ➕ Total de las calificaciones
- 📊 Promedio de la clase

Si no se introduce ninguna calificación, el programa muestra un mensaje indicando que no se introdujeron calificaciones.
