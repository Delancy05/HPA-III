### 🔄 Problema 4: Recursividad — Factorial

En este problema se implementó una función **recursiva** para calcular el factorial de un número.

La función se llama a sí misma hasta alcanzar el caso base establecido para detener la recursividad.

El cálculo realizado corresponde a:

**n! = n × (n - 1) × (n - 2) × ... × 1**

Se tuvo en cuenta el caso base para evitar una recursividad indefinida y posibles errores de desbordamiento de pila (`StackOverflow`).

### 📊 Problema 5: Frecuencias

En este problema se desarrolló un algoritmo en C# para determinar la **frecuencia de los elementos** dentro de un conjunto de datos numéricos.

El programa recorre los datos y contabiliza cuántas veces aparece cada número, mostrando los resultados de manera organizada en la consola.

Se trabajó con:

- 🔢 Conjunto de números.
- 🔎 Búsqueda de elementos repetidos.
